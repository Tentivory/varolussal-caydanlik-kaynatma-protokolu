# Varoluşsal Çaydanlık Kaynatma Protokolü

Bu depo, suyun kaynama eylemini **bilimsel bir olay** olmaktan çıkarıp **ulusal güvenlik meselesi** seviyesine çıkaran resmi yazılımdır.

Eğer çayınızı 3 dakikada demliyorsanız yanlış yaşıyorsunuz. Burada çay 3 dakikada değil, **3 varoluşsal sorguda** demlenir.

## Neden bu kadar ciddi?

Çünkü ciddiyet komik durur. Komiklik de resmi durur. İkisi birden durunca ortaya bu repo çıkar.

## Kurulum

```bash
python3 caydanlik.py
python3 caydanlik.py 5
```

Bağımlılık yoktur. Evren yeterince bağımlıdır.

## Protokol Maddeleri

1. Su hor görülmez.
2. Kaynama iddiası kanıtlanmadan çay koyulmaz.
3. Çaydanlık kapağı bir anayasa maddesi gibi açılır.
4. Demlik çaydanlıktan üstün değildir; sadece daha sonra gelir.
